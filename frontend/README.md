# TaskFlow — ДЗ4. Frontend для FastAPI Task API

React + TypeScript + Vite. Реализованы: просмотр, создание, редактирование, завершение, удаление задач; поиск, фильтр, состояния loading / empty / error и responsive UI.

## Локальный запуск
```bash
npm install
npm run dev
```
Откройте адрес, который выведет Vite (обычно `http://localhost:5173`; в сессии Cursor документа 4480 использован порт `5174`). По умолчанию работает **самодостаточный mock-режим**, не требующий backend. Данные временные и сбрасываются после перезагрузки страницы.

## Проверки
```bash
npm test
npm run build
```

## Подключение ДЗ2/DЗ1 FastAPI
1. Запустите API и проверьте `/openapi.json`.
2. Скопируйте `.env.example` в `.env` и задайте `VITE_API_BASE_URL=http://127.0.0.1:8000`.
3. Убедитесь, что у сервера настроен CORS для `http://localhost:5173`.
4. Сверьте HTTP-метод обновления (PATCH/PUT) с OpenAPI, при необходимости измените `VITE_API_UPDATE_METHOD=put`.
5. Сверьте DTO Task (`id`, `title`, `completed`) и формат ответов. **Исходники API ДЗ1 присутствуют в отдельном архиве**, но интеграция с работающим backend и CORS не подтверждена; перед запуском сверяйте endpoint и поля.

## Структура
`src/App.tsx` — экран; `src/components` — форма и таблица/карточки; `src/api/tasks.ts` — адаптер реального/демо API; `src/tests` — автоматические тесты; `src/styles.css` — адаптивные стили.

Демо без авторизации и постоянного хранения. Не публикуйте открытый FastAPI API в интернет без контроля доступа. Скриншоты/логи разработки и отчёт находятся в `evidence/` и `development_report.md`.
